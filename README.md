# 🌌 Dark Energy Architect Portfolio

A premium, ultra-modern portfolio website with gravitational animations, cosmic pulses, and AI assistant. Built for senior architects and technical leaders.

![Dark Energy Portfolio](assets/images/preview.png)

## ✨ Features

- **Gravitational Animations** - Real-time particle physics simulation with mouse interaction
- **Dark Matter Panels** - Floating interactive panels with spring physics
- **Cosmic Pulses** - Slow, rhythmic background animations
- **AI Assistant** - Cinematic architectural guidance interface
- **Ultra-Minimal Transitions** - Smooth, professional page transitions
- **25 Pages** - Complete portfolio with projects, insights, and case studies
- **Responsive Design** - Mobile-first, works on all devices
- **Performance Optimized** - Lazy loading, debouncing, throttling
